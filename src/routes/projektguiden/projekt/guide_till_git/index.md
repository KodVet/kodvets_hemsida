Git är ett verktyg som hjälper till med bland annat versionshantering. När man jobbar i projekt tillsammans är det ett användbart verktyg för att spåra ändringar, undvika att man skriver över varandras ändringar, underhålla olika versioner samtidigt och mer. Med versionshantering kan du känna dig mer säker på att du inte kommer förlora någon fungerande kod som du sparar, vilket tillåter dig att experimentera med saker utan att känna dig orolig för att du inte ska kunna gå tillbaka till hur det var tidigare.

Om ett git-repo använder sig av t.ex. Github eller Gitlab så kan man dessutom navigera runt bland filerna i webbläsaren. Denna fil (samt resten av sidan) kan du komma åt genom t.ex. https://github.com/KodVet/kodvets_hemsida/tree/master/src/routes/projektguiden/projekt/guide_till_git/index.md
